Round 54: Custom icons everywhere: physical constants, := , unpin, menus, and every last Material icon replaced (as built)

Physical constants get symbol icons like π and e: the symbol in the accent color, subscripts and superscripts small in ink (c, h, ℏ, kB, G, ε0, μ0, me, NA, R∞…). := (define a symbol) and the list of constants have their own; the matrix key is in plain ink like the others; the symbol builder is one color. Unpin is a pin struck through, so it never looks like Pin. The ⋮ menus now have icons (copy last answer, clear variables, unit converter, settings, acknowledgements, clear history), Use the answer has its own, and every remaining Material icon (close, check, add, ⋮, backspace, enter, grip, swap, open elsewhere, language, bug report, help, warnings, stars, save, fonts, expand, full screen, move, the arrows and chevrons…) is now one of the app's own.
