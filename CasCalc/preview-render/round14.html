Point popup

Tap or drag on a curve. The card floats above the point (below it near the top edge) with a tail pointing at it. The header has the line's color dot, the kind of point as a tonal chip (Maximum, Zero, Intersection…) and the line's name. Each coordinate gets its own row in large numerals with a Use button that puts it in the calculator. The area actions come last as tonal buttons, shown only when they apply. Before: the old dark pill (left).

Constants sheet

The More constants key opens this sheet: a search bar, category chips (Universal, Electromagnetic, Atomic and nuclear, Physicochemical, Adopted), then the constants grouped in rounded cards. Each row shows the symbol in a tonal tile, the name, and the value in math type with its unit. Exact SI values get an exact chip. Tap a row to insert the constant; the copy button copies its value. The unit system (SI / Planck / atomic / natural) is shown top-right and changes the values listed.
