UI review · what I'd improve

  1. Key groups are icon-only. Eleven glyphs (√ ⊿ ⚖ ∇ [:] ℂ ⚛ |M| …) are hard to learn and nothing says which group is open. Proposal: the open group widens to show its name, the rest stay compact (an M3 Expressive button group), so it still fits.
  2. Mode switcher is icon-only too (3D and complex look alike at a glance). Same fix: the current mode shows its name.
  3. History cards compete for attention. Graph and share icons sit beside the question, the answer is the same weight as the input. Proposal: the answer is the largest thing, actions become a small chip row (≈ decimal · graph · copy · more) under it, only on the newest card or a tapped one.
  4. The live preview is easy to miss. It's a small gray line. Proposal: "= " in the primary color, a little larger, so you see the answer before pressing ↵.
  5. Graphs start blank. New users don't know the syntax (points, (cos t, sin t), regions, f(x, y), vector fields). Proposal: an empty-state card with tappable examples, each labeled with what it draws, and an extended "Add" button.
