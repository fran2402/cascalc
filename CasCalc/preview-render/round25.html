Many more spreadsheet functions (beta)

The data table's formulas now cover about 375 Excel function names. They include statistics and tests (T.TEST, CHISQ.TEST, PERCENTILE, RANK, SKEW, KURT…), distributions and their inverses (NORM, T, χ², F, binomial, Poisson, gamma, beta, Weibull…), lookups (VLOOKUP, HLOOKUP, XLOOKUP, INDEX/MATCH, OFFSET, INDIRECT), logic (IFS, SWITCH, IFNA), text (TEXT, TEXTJOIN, SUBSTITUTE, LEFT/MID/RIGHT…), dates (DATE, DATEDIF, NETWORKDAYS, EOMONTH…), finance (PMT, NPV, IRR, XIRR, depreciation) and engineering (CONVERT with the app's units, base conversions, bits, Bessel, complex numbers). Formulas can now return text as well as numbers. The ƒx list has a search box and a chip for each group.
